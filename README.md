# 📝 Todo List App

Простое и элегантное приложение для управления задачами, написанное на чистом JavaScript с использованием современных веб-технологий.

![JavaScript](https://img.shields.io/badge/JavaScript-ES6+-yellow)
![CSS](https://img.shields.io/badge/CSS-Modular-blue)
![HTML](https://img.shields.io/badge/HTML-Semantic-orange)
![License](https://img.shields.io/badge/License-MIT-green)

## ✨ Особенности

- 🎯 **Добавление задач** — быстрое создание новых задач через форму
- 🔍 **Поиск задач** — мгновенная фильтрация по названию
- ✅ **Отметка выполненных** — отслеживание прогресса с помощью чекбоксов
- 🗑️ **Удаление задач** — индивидуальное удаление с анимацией
- 💾 **Локальное хранилище** — все задачи сохраняются в localStorage
- 📊 **Счетчик задач** — отображение общего количества задач
- 🧹 **Массовое удаление** — очистка всех задач одной кнопкой
- 🎨 **Адаптивный дизайн** — корректное отображение на всех устройствах
- 🚫 **Graceful Degradation** — корректная работа даже без `crypto.randomUUID()`

## 🚀 Демо

Просто откройте `index.html` в любом современном браузере — приложение готово к использованию!

## 🛠 Технологии

- **Vanilla JavaScript (ES6+)** — без фреймворков и зависимостей
- **CSS Modules** — модульная структура стилей
- **LocalStorage API** — персистентное хранение данных
- **Event Delegation** — эффективная обработка событий
- **CSS Animations** — плавные анимации удаления задач
- **HTML5 Semantic Markup** — семантическая верстка
